### 挂机方案

围绕“方案是什么 → 投注数字 → 选号原因 → 参数 → 资金路径 → 风险 → 历史验证 → 下载 → 更新日志”形成标准内容模板。下载页不得只有文件链接，必须保留可索引的完整说明。

### 数据实验室

优先发布原创验证内容：历史数据、规则、样本长度、参数、结果、连续不中、最大资金暴露、失败案例、复算方法。实验内容用于建立与普通推广站不同的原创资产。

### 平台评测

平台评测必须基于可核验字段，不以佣金高低决定“信誉”。建议固定比较：玩法支持、奖金/返点、最低投注、充值提现规则、客服、移动端、挂机兼容、测试日期、优点、限制、异常记录和商业合作披露。

## 关键词防冲突规则

- 一个主关键词只指定一个 Primary URL。
- 同一搜索意图不得创建多个近似页面。
- 旧页面有价值时优先 UPDATE/MERGE，不机械新建。
- 新文章必须有独立的信息增量；仅替换“分分彩/哈希分分彩/奇趣分分彩”等词的换皮稿禁止发布。
- “稳赚、必中、100%中奖、稳定盈利”等不可证明承诺禁止作为页面主张。

## 当前 URL 策略

现有文章继续保留 `/index.php?c=show&id={id}`，现阶段不为 SEO 强行改 URL，以免破坏已有链接和潜在收录。新专题 URL 在 CMS 栏目结构完成后再确定，并通过 Keyword Map 统一管理。
